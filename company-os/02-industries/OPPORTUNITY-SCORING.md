# Opportunity Scoring System

Score each industry (or individual prospect) with simple factors. Re-rank quarterly as you learn.

## Factors

| Factor | Score |
|--------|------:|
| Still paper-based | +3 |
| Uses spreadsheets heavily | +2 |
| Employees in field | +2 |
| Repetitive quoting | +2 |
| Scheduling complexity | +3 |
| Compliance paperwork | +2 |
| Owner overwhelmed | +3 |
| Existing software hated | +2 |

## How to use

1. Score the **industry** in each `opportunity-score.md` under `02-industries/<vertical>/`.
2. For a **specific company**, copy factors into `03-prospects/.../workflow-analysis.md` and adjust.
3. Maintain a summary table in `01-market-intelligence/high-friction-industries.md`.
