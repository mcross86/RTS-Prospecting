# AI playbooks

Cross-cutting prompts and patterns. **Product-specific prompts** often live in `05-products-and-templates/<product>/cursor-prompts.md`.

## Layout

- `prompts/` — copy-paste task prompts
- `architecture-patterns/` — stack decisions, tenancy, RLS notes
- `deployment-patterns/` — hosting, env, CI
- `ui-patterns/` — layout, components you like
- `debugging/` — common failure modes and fixes
- `reusable-agents/` — descriptions for repeated Cursor agent setups
