# Internal OS — recommended tooling

| Layer | Tool |
|-------|------|
| Files + graph | Obsidian (optional) on this folder |
| Version control | Private GitHub repo |
| Lightweight internal apps | Supabase |
| Lead tracking | Airtable or NocoDB |
| AI editing | Cursor rules + `08-ai-playbooks` + per-product `cursor-prompts.md` |
| Models | Claude / OpenAI as you prefer |
| Async explainers | Loom |

Keep secrets out of markdown; reference a password manager or `.env` in repos.
